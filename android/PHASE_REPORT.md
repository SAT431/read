Folio is a native Kotlin/Compose Android app for private NEET preparation. **Gemini 3.5 Flash-Lite** and Groq Whisper Large v3 are called directly from Android using user-entered keys encrypted with Android Keystore. PDF import, selected-page extraction/cropping, caching and learner-state recovery run on Android. Hosting is not required. The full original feature scope remains active.
