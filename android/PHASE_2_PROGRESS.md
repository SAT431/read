## Implemented

The separate service/ package implements authenticated Gemini orchestration and Groq Whisper Large v3 transcription. Gemini receives a versioned utterance/context/execution-result envelope and returns a nullable AppCommandBatch. Server validation rejects wrong request IDs/revisions, unknown/disabled actions, malformed fields and unknown library references. Android remains the final authority for complete source, educational-data and interaction-policy validation. Clarifications and text-only replies have no action batch.

Service requests are bounded before parsing, audio is capped at 12 MB and not persisted, provider concurrency and rolling request rate are bounded, credentials are excluded from object representations, redirects are disabled and provider errors are sanitized. Quota responses preserve bounded retry information without automatic retries or alternate paid providers. This service has not changed account billing or guaranteed a project's free quota.

The new data:remote Kotlin/JVM module implements HTTPS-only service configuration, bounded transport and a typed MentorProvider. Provider keys never enter the native configuration. Wire responses must match the captured revision and request ID and decode into actual AppCommand types. The service access token is separate from Gemini/Groq keys.

AppCapabilityContext now explicitly serializes schemaVersion/default fields and exports current activities, components and focused component alongside curriculum/library/context/preferences. This fixes a real serializer omission that would have caused rejection by the service.
