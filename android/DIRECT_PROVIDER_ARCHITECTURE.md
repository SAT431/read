## Active paths

- **Credentials:** ProviderKeyEditor accepts Gemini/Groq keys and automatically selects gemini-3.5-flash-lite, verified against Google's model/pricing pages on 15 October 2026. KeystoreProviderProfileStore encrypts both keys with AES-256-GCM using a non-exportable Android Keystore key, authenticated record identity and atomic writes. Its mutex-protected model migration preserves both keys and rewrites the encrypted record once. The record stays in noBackupFilesDir. UI summaries expose only configuration flags/model name; key fields are masked and excluded from saved-instance state. Blank fields keep previously saved keys; Remove saved keys clears the record.
- **Mentor:** AssistantSession captures actual chapter/PDF/page/activity/component context and revision. DirectGeminiMentor calls Gemini generateContent with the packaged prompt and strict JSON envelope. Typed responses must match request/revision and advertised actions; the existing atomic native runtime still validates IDs, source ownership, pins and interactions before executing effects.
- **Speech:** Tapping Speak starts bounded foreground AAC/M4A capture and enables automatic submission. EndOfSpeechDetector samples local microphone energy; after sustained speech and a roughly 1.2-second quiet pause, capture finishes, DirectGroqTranscriber invokes whisper-large-v3, and the transcript goes through the same Gemini action path as typing. Stop remains optional, not required. Silence times out without a provider call. Failed handoff preserves the draft; voice.review opens Assistant and scrolls the transcript into view even if the same tab was already open. The old review-first mode switch is disabled. Backgrounding cancels active capture/transcription; temporary audio is deleted. Energy-based endpointing still needs real-device/noisy-room tuning and is not a wake-word listener.
- **PDF engineering:** LocalPdfPageExtraction verifies the immutable original checksum, copies exactly the selected page with PDFBox Android and extracts available text without OCR. Gemini receives that original page plus deterministic text and returns only a provisional structured draft. LocalPageEngineer validates bounds and structure, assigns source IDs, invokes NativePdfTools to crop original rendered pixels, and builds a separate token-discrepancy/uncertainty report. Scans may have no text layer; this report does not prove accuracy.
- **Cache:** EngineeringCoordinator and RoomPageRepository retain validated unchecked pages and separate fidelity metadata by document checksum/page/engineering version. Original PDFs, original image crops and workspace/quiz/reading state remain in private Android storage. Cache reuse does not call Gemini again. Existing imported PDFs and source-cache rows are preserved.
- **Reading:** SentenceIndex derives stable passage-owned UTF-16 sentence ranges without changing transcription. The prebuilt reader uses selectable continuous text with focus annotations; reader.focus_sentence rejects unknown or other-page sentence IDs. Boundaries are deterministic reading aids, not a claim of linguistic/transcription perfection.

## Module boundaries

core:model defines credential/extraction/provider ports and domain data. data:local owns Keystore, PDFBox/PdfRenderer and Room. data:remote owns fixed-destination provider HTTPS and strict responses, with no Android UI dependencies. core:runtime owns command/state/source validation and reading targets. feature modules receive state/callbacks; the app composition root assembles LocalPageEngineer and the concrete providers. Each production file remains subject to the 200-line architecture check.

HttpsProviderTransport restricts destinations to generativelanguage.googleapis.com and api.groq.com, rejects other paths, validates TLS through Android, bounds request/response sizes, cancels connections and follows no redirects. Provider keys go in authentication headers, not URL parameters. RetryingProviderTransport wraps Gemini mentor/page requests: at most three identical requests for HTTP 500/502/503/504, cancellable 1/2-second backoff or Retry-After capped at five seconds. Authorization, quota and malformed successful replies are not retried. Groq has no automatic upload retries. No paid fallback or model switch occurs. Free quota depends on the user's actual provider project; Folio does not change billing settings.
