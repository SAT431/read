Implemented and device-checked 16 October 2026. The dedicated full-screen STUDY route is installed in place. After helper acceptance, six distinct tablet checks passed, including real Gemini mapping of the uploaded Botany Cell PDF and a generated-PDF mentor selection/preparation/answer flow. These are focused workflow checks, not full textbook-fidelity or production acceptance.

## User journey

Study with AI opens the PDF's topic map in the full app window, without the global sidebar/bottom navigation. Original PDF viewing also uses the full window and adds Fit width. Returning from the original restores the study route. Missing documents retain saved records and offer a visible route home.

The map is built by direct Gemini 3.5 Flash-Lite calls over original PDF batches, not an OCR-only summary. Each topic has an overview, subtopics, original PDF page range and provisional diagram flag. Android validates global zero-based page indices and normalized first/last-page vertical ranges. Uncovered pages are explicitly listed for original inspection; they are not silently classified. Topic choices are stored against the exact map fingerprint and document checksum.

Preparing today's selected topics uses the existing bounded native page-engineering jobs. Only selected pages are requested; available text plus multimodal reconstruction produce original-linked paragraphs and native crops of original diagram pixels. The full-height reader uses those selected regions, selectable sentence text and original figures. Regions include overlapping source elements intact rather than cutting sentences/diagrams arbitrarily. Source wording/reconstruction/corrections and learner records remain separate. Machine output is not marked verified.

A persistent Study companion contains actual assistant messages, typed input and hands-free Speak. It stays in the study session rather than opening a separate assistant tab. Chat can fold while retaining the local draft; guided-reading controls remain available when not typing. IME-aware sizing hides chat history/guide controls while composing so input/Send have room. Questions use the existing real Gemini provider/context/runtime. No simulated AI answers are shipped.

Guide my reading selects a native sentence. Yes, next line records only that exact current sentence as reported read and advances across selected pages; the final sentence ends guidance. English spoken yes/done/finished shortcuts use the same typed command after Groq transcription. The current guide version/line is captured at recording start; a changed highlight rejects the old spoken confirmation. Pause/topic changes never confirm reading. Native source/plan/version checks reject stale or fabricated targets. Reopening restores the exact saved guided page and sentence without marking another line read. Returning to topics/pausing remains possible when the map changed.

## Architecture and recovery

DocumentOutlineRepository/DocumentChunkSource/DocumentMapper are model ports. AtomicDocumentOutlines stores a bounded validated checksum-keyed private map with AtomicFile and protects malformed originals. LocalDocumentChunks verifies the private original checksum and preserves page resources, crop/media boxes and rotation. It copies at most eight original pages, reduces overly large batches to the 12 MB transfer bound and releases temporary files. Truncated model output causes bounded smaller batches; malformed regions/JSON and quota/auth failures do not become fake results. Completed batches persist before continuing and explicit Resume analysis retries only remaining work. Index completion never steals navigation.

This original-PDF inline input is supported by [Google's document-understanding API](https://ai.google.dev/gemini-api/docs/document-processing). The native eight-page/12 MB limits are Folio's conservative transport choices, not a promise that a whole uploaded document fits in one request.

DocumentIndexingSession and StudyPreparationSession own app-scoped work/progress/cancellation. Existing PagePreparationJobs deduplicates source work; cancellation stops scheduling/waiting while an already-requested shared page may still cache. Retry versions prevent an old completion/error from replacing a new selection's progress. Only current engineering-version pages enable the guide.

DocumentStudyPlan is additive durable workspace state, validated independently of current source availability. DocumentStudyReducer, StudyGuideReducer and StudyTargetFocus implement shared typed actions. AppActionRegistry advertises the connected study actions only inside STUDY; Gemini gets bounded current topic IDs, fingerprint, plan/version and actual source context, never keys or local PDF paths. Selection/preparation/guide/page/sentence/pause actions all use the common atomic execution path. Original learner records are retained; confirmations retain explicit user/assistant provenance. No model-generated UI or extraction script runs.
